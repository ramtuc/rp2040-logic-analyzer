# JLCPCB 正規製造データ

このフォルダには、**A0 の注文に実際に使った製造データをそのまま置きます**（Gerber は JLCPCB の注文ページからダウンロードしたもの、BOM / CPL は注文時にアップロードしたファイル）。 ファイル名は配布のままで、変更しません。**実装の正（正規データ）はこのフォルダのファイル**です。

## 中身

| パス | 何か | 出どころ |
|:---|:---|:---|
| `gerbers/`（16 ファイル） | A0 の注文（2026-09-26）で製造に使われた Gerber・ドリル・`.gbrjob`。KiCad 10.0.3 の出力（2026-09-21 22:40 JST） | 注文ページ「Production file」の `yg/` フォルダ |
| `jlcpcb-render-top.png` / `jlcpcb-render-bottom.png` | アップロードした Gerber から JLCPCB 側が自動生成したプレビュー（表はシルクとパッド、裏はパッドのみ） | 同上 |
| `bom-jlcpcb.csv` / `cpl-jlcpcb.csv` | A0 の注文でアップロードした BOM と CPL（kicad-cli の出力を JLCPCB 形式に整えたもの。`../out/` の同名ファイルと同一） | 注文に使ったファイルそのもの |

`../out/gerbers/` にある Gerber は、同じ基板データ（`../rp2040-logic-analyzer.kicad_pcb`・2026-09-21 22:04 保存）を kicad-cli で 2026-09-22 に出力し直したものです。中身の違いは次の 2 点だけで、穴と銅のデータは同じです。

- ファイル中の出力日時
- 長穴 6 か所（USB-C シェルの脚 4 × 0.6mm、SW1 の固定脚 2 × 0.8mm）の記法。注文した側は KiCad GUI の「代替ドリルモード」（`G00`/`M15`/`G01`/`M16`）、`../out/gerbers/` は `G85` のルート指令

## 同梱していないもの

- JLCPCB 内部の CAM 出力（ダウンロードの `ok/` フォルダ。注文番号付きのアーカイブと層ごとの中間ファイル）
- 解析用 JSON（`4te.json` など。JLCPCB 社内のパスや期限付き URL を含む）

## 注意

- A0 の注文では、USB-C（J1）を部品が入手できなかったため実装から外しています。このフォルダのデータは、その状態の注文のものです
- A0 の PCB は SW1 のコモンの配線が誤っています（コモンはピン 2）。改修方法はリポジトリ直下の README の「既知の問題」を参照してください

# JLCPCB manufacturing data (authoritative)

This folder holds the manufacturing data actually used for the A0 order, stored as-is with the original file names (Gerbers downloaded from the JLCPCB order page; BOM / CPL as uploaded). These files are the authoritative data for the A0 order (2026-09-26).

- `gerbers/`: the 16 Gerber / drill / `.gbrjob` files used for fabrication (KiCad 10.0.3 export, 2026-09-21 22:40 JST). `../out/gerbers/` is a later kicad-cli export of the same board file; the only differences are the timestamps and the encoding of the six oval slots (route commands `G00`/`M15`/`G01`/`M16` vs `G85`).
- `jlcpcb-render-top.png` / `jlcpcb-render-bottom.png`: previews generated by JLCPCB from the uploaded Gerbers.
- `bom-jlcpcb.csv` / `cpl-jlcpcb.csv`: the BOM and CPL uploaded for the A0 order (identical to the files of the same name in `../out/`).
- Not included: JLCPCB's internal CAM output and analysis JSON files.

In the A0 order, the USB-C connector (J1) was excluded from assembly because the part was unavailable. The A0 PCB wires SW1's common incorrectly (the common is pin 2); see "Known issues" in the top-level README.
